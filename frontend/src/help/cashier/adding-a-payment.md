# Adding a payment

When a customer pays more against a job that already has a receipt, you **add a line** to that receipt — you never start a second one.

## Steps

1. Find the customer and open their history.
2. On the job card row, check the **Balance**. If there's an open balance, an **Add Payment** button shows.
3. Press **Add Payment**. The box shows the balance due and which line it will add (e.g. `OOR-AUG26-R-001-L2`).
4. Enter the **Date**, **Settlement Mode** and **Amount** (it defaults to the full balance).
5. Add Bank / Transaction ID if the mode asks for them.
6. Optionally **attach a receipt** (PDF or image).
7. Press **Add Payment**.

The balance updates straight away. When it reaches zero the receipt **settles itself** — no close button.

## When Add Payment isn't there

- The balance is already zero, or
- the job card belongs to **another branch**. Only that branch's cashier can record the payment.
