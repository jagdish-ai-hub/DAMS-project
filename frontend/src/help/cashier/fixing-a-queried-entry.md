# Fixing a queried entry

When the Accountant sends an entry back with a question, it shows as **Queried**. You fix it and resubmit — it keeps the same number.

## Steps

1. Open **My Entries** from the home screen.
2. Queried rows are highlighted in amber, with a **Fix & Resubmit** button.
3. Press it to open the entry in edit mode.
4. Correct the header fields or settlement lines as needed.
5. Press **Resubmit**.

The entry goes back to **Submitted** and returns to the Accountant's queue. Its DAMS-Receive-ID does not change.

## Notes

- Only **Draft** and **Queried** entries can be edited. Once an entry is Verified or Approved you can still **Add Payment**, but you can't change existing lines.
- If you disagree with the query, add a **Remark** explaining before you resubmit.
