# Creating a receipt

A receipt records money a customer paid you against one job / cause.

## Start a new receipt

1. From the home screen press **New Receipt**, or open a customer and press **＋ New Receipt** on their card.
2. Fill the header:
   - **Customer Name** — required. Pick from the box, or type a new name.
   - **Vehicle #**, **Job Card / DBM**, **Invoice #** — as you have them. All optional.
   - **Tran. Category** and **Status** — pick from the lists your Owner set up.
   - **Invoice Amount** — the full bill. Leave blank for a plain advance.
   - **Transaction Type** — **B2B** if the customer is a registered business; then a **GST#** is required.
3. Add one **Settlement Line** per payment received:
   - Date, **Settlement Mode**, **Receive Amount**.
   - Bank and Transaction ID appear only when the mode needs them.
4. Watch **Pending** at the bottom — invoice amount minus what you've entered.

## Save Draft or Submit

- **Save Draft** keeps the receipt editable. It has **no number yet**.
- **Submit** sends it for checking and assigns the **DAMS-Receive-ID** (e.g. `OOR-AUG26-R-001`). This number is permanent and gap-free.

You can only create receipts for job cards in **your own branch**.
