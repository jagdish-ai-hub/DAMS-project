# Onboarding an organization

Every dealership group is a separate **organization** — its own branches, users, master lists and data, walled off from every other. Setting one up is a two-minute job: you create it and its first owner, then hand that owner an invite link.

## Step 1 — create the organization

1. Open **Organizations** — your home screen.
2. Under **Onboard a new organization**, fill in:
   - **Organization name** — the dealership group's name.
   - **First owner — name** and **email** — the person who'll run the setup from here.
3. Press **Create organization & invite owner**.

The organization is created with one user: that owner, in an **invited** state — they don't have a password yet. It also starts with a default set of master lists so the owner isn't staring at empty dropdowns.

## Step 2 — send the invite

There's no email in this version, so you pass the link on yourself:

1. A green box appears with the **invite link**. Press **Copy link** (it confirms with **Copied ✓**).
2. Send it to the owner however you normally reach them.
3. They open it, set a password, and sign in. From there the organization is entirely theirs — branches, team, masters, transactions.

The link is **single-use and expires.** If it lapses before they use it, delete the organization and create it again, or have them use **Forgot password** once they've signed in at least once.

## Managing existing organizations

The **All organizations** table lists every org with its created date, cashier-access mode and status.

- **Deactivate** — blocks every user in that org from signing in. Their data is untouched. **Activate** restores access.
- **Delete** — permanently removes the organization and **all** of its data: branches, users, masters, job cards, documents, audit history. You have to type the organization name to confirm. This cannot be undone.
