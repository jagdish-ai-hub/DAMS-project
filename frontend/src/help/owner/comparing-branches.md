# Comparing branches

The **Branch comparison** panel on the dashboard lines every branch up against each other for the period you've selected. It's the quickest way to see which branch needs attention.

## The columns

- **Collections / Expenses / Net** — approved money in and out, same rules as the headline cards.
- **Cash** — that branch's live drawer position right now.
- **Last close** — when the branch last closed its cash day, plus the variance if it wasn't zero. **"never"** means that branch has never run a cash close.

## What to look for

- A **stale last close** (several days ago) or a **non-zero variance** means the drawer figure for that branch is less reliable until someone closes the day properly. Worth a phone call.
- To dig into one branch, switch the dashboard's branch filter to it — the whole page (trend, mode split, outstanding, activity) narrows to that branch.
